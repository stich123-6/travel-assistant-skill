# 场景准备清单

根据本次目的选择必要事项。没有证据时用“建议检查”，不要把场馆报名、材料上传、证件要求说成已完成或强制要求。

| 场景 | 建议检查 |
| --- | --- |
| 普通参会 | 邀请函、签到码、会议材料、笔记设备、电脑与充电器、对接人 |
| 参观展会 | 门票/预约码、入场时间、展馆入口、关注展商或展位、名片 |
| 展商参展 | 展商证、布展/撤展安排、展位信息、样品、宣传资料、名片、运输或携带安排 |
| 外地出行 | 实际交通票据、适用身份证件、车站/机场、接驳位置、必要住宿、行李、充电设备 |
| 商务拜访 | 对接人、已知联系方式、访客登记、拜访材料、会场入口 |
| 个人出游 | 预约票、开放时间、必要行李、路线、同行人已明确的需求 |

先区分参观展会与作为展商参展；只有样品/展位/布展等信息确实影响准备时补问角色，不因此阻塞交通查询。仅需本市开会时不要附上无关的机票或住宿清单。

准备提醒可提议：前一天核对材料、出发前检查随身物品、到场前查看入口。每项提醒都要有具体日期、时刻、时区和可执行渠道。用户同意前只是建议，任务未创建前不能承诺到点通知。

用户标记某项已准备，则更新状态并取消或调整本记录内尚未触发的重复催办（需真实任务能力），不要无条件继续提醒。天气信息只引用实际查询覆盖日期；远期不能预测时建议临近复查。
